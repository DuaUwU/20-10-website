WEBSITE 20/10 — BẢN TƯƠNG TÁC CHO ĐIỆN THOẠI

Tính năng:
- Giao diện toàn màn hình, không cuộn trang.
- Chạm để chuyển màn hình.
- Phong bì mở bằng hiệu ứng animation.
- Trái tim bay, hiệu ứng lấp lánh.
- Nhạc nền giai điệu tự tạo bằng Web Audio (không cần file nhạc ngoài).
- Nút bật/tắt nhạc.
- Responsive cho điện thoại.

Xem thử:
1. Giải nén ZIP.
2. Mở index.html bằng Chrome/Edge.

Đưa lên GitHub Pages:
1. Tạo repository Public tên 20-10.
2. Add file > Upload files > tải index.html lên > Commit changes.
3. Settings > Pages > Deploy from a branch.
4. Chọn branch main và folder /(root), nhấn Save.
5. Chờ xuất bản rồi mở link dạng https://TEN-TAI-KHOAN.github.io/20-10/

Lưu ý nhạc:
Điện thoại thường chặn tự phát nhạc. Nhạc sẽ bắt đầu sau khi người xem chạm nút “Mở món quà của bạn”.
